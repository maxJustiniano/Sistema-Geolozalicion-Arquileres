Workflow para publicar propiedades

Roles y autorizaciones

  • Viewer: Solo consulta.
  • Publisher: Puede crear/editar propiedades.
  • Admin: Asigna roles y aprueba publicaciones.

Flujo sugerido

  1. Autenticar al usuario (JWT, Sanctum, etc.).
  2. Validar permisos (role === 'publisher').
  3. Subir imagen a storage (S3/local) y guardar URL.
  4. Guardar la propiedad en DB.
    {
  "title": "Casa", 
  "price": 850000,
  "coordinates": {"lat": -26.18, "lng": -58.17},
  "images": ["https://.../foto1.jpg"]
}
  5. Opcional: workflow de revisión antes de publicar.

Endpoints sugeridos

  • GET /api/roles/me → roles actuales.
  • POST /api/properties → crear propiedad.
  • POST /api/properties/{id}/images → subir imágenes.
  • POST /api/roles/request → solicitar rol publisher.

Integrar el formulario utilizando fetch o Axios y manejar las respuestas de la API con mensajes claros al usuario.
